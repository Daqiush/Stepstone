# 复数模式设计

## 目标

在主页提供复数模式入口，其中复数麻将为不可用入口，复数桥牌提供两人、两方、四手独立出牌的完整一局玩法。

## 房间与界面

房间沿用三位房间号。两个玩家分别代表南北与东西；每方控制各自的两个座位，但北、东、南、西仍按顺时针独立出牌。复数桥牌使用独立页面，双方仅收到自己一方的两手牌。

每手牌以复平面坐标矩阵展示：纵轴为 5i 至 1i，横轴为 1 至 5。普通牌的显示顺序区分虚牌 `bi+a` 与实牌 `a+bi`；两张 Ace 单列显示。

## 规则

牌堆包含每个坐标的虚、实两张牌（共 50 张），以及 `A+Ai`、`Ai+A`。叫牌阶段两方同时提交 1–13 墩与本方可选将牌：南北选实部纵列，东西选虚部横行。墩数优先、花色数字次之、完全相同由服务器抽签。

非 Ace 引出的花色按引出方向与固定坐标确定；同一横/纵线上，同坐标的引出方向牌优先，再按另一坐标由 5 至 1 排序。必须跟随本墩花色。将牌优先，且 Ace 仅在将牌花色中参与排序；实部将牌时 `A+Ai` 高于 `Ai+A`，虚部将牌时顺序相反。

## 状态与验证

新增 `complex` 房间模式及 `COMPLEX_BIDDING`、`COMPLEX_PLAYING`、`COMPLEX_SCORING` 阶段。后端负责洗牌、私发、同步叫牌、合法出牌、赢墩与断线重连快照。13 墩后按庄家叫牌目标判定成约或宕约。
